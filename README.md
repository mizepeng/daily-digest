# 每日早报 · 游戏与 AI

**网址：https://mizepeng.github.io/daily-digest/**

每天早上 8 点（新加坡时间）更新的资讯早报，分「游戏」和「AI」两个板块，各 12 到 20 条，按「重要 / 值得关注 / 简讯」分层。游戏以 PC 为主，AI 覆盖主要实验室、产品发布、开源模型、研究和行业动态。每条附原始来源链接，往期可以按日期切换查看。

纯静态站点，零构建，用 GitHub Pages 从 main 分支根目录发布。

## 文件

- `index.html`：页面本身，读取 `data/` 里的 JSON 渲染，平时不用改。
- `data/index.json`：所有期的日期列表，`{"dates": ["2026-11-27", "2026-11-26"]}`，顺序不限，页面会按新到旧排。
- `data/YYYY-MM-DD.json`：每一期内容。
- `logo.svg`：网站 logo，也是浏览器标签图标。
- `.nojekyll`：让 GitHub Pages 原样发布文件。

## 每期 JSON 格式

```json
{
  "date": "2026-11-27",
  "updated": "2026-11-27T00:00:00Z",
  "games": { "important": [条目], "notable": [条目], "brief": [条目] },
  "ai":    { "important": [条目], "notable": [条目], "brief": [条目] }
}
```

条目：

```json
{
  "title": "一句话标题",
  "summary": "一两句说明",
  "url": "https://原始来源或实际读过的页面",
  "source": "来源名称，转述时写「某某（转述 某某）」",
  "date": "11-27",
  "tag": "你在玩",
  "image": "https://来源页面的 og:image",
  "image_alt": "图片的简短说明"
}
```

`tag` 可省略，只给 Dota 2、巫师3重制版、狂热运输3 的条目加。`url` 必须以 https:// 开头，否则标题不带链接。每个板块合计 12 到 20 条。

### 链接语言（`url`）

- 适用于所有来源：只有当「同一个来源网站」提供「同一篇文章」的简体中文版时，`url` 才换成简体中文版（比如官网的语言切换、Steam 公告的语言版本）；没有简中但有繁中时用繁中；都没有就用原文。
- 绝不换成别的网站的中文转载、聚合页、新闻列表页或翻译页。
- `url` 要直接指向这篇新闻本身，不用聚合站的当日列表页。条目来自聚合站时，换成它转述的原始报道（读过的那一页）。
- 中文版地址必须真正打开读过：用网站自己的语言切换或页面上的链接找到，确认落地页就是这篇文章本身；不要自己改地址里的语言代码去猜。
- 例：巫师官网 `/zh-cn/` 新闻页，Steam 新闻加 `?l=schinese`。
- 换成中文版后，`image` 可以沿用原文页面的图。

### 配图（`image` / `image_alt`）

- 可省略。页面上「重要」的条目都会显示一张大图，没有 `image` 或图片加载失败时，自动换成按来源生成的封面；「值得关注」有图才显示缩略图；「简讯」不显示图片。
- 只用这条 `url` 指向、并且真正读过的那个页面自己的 `og:image` 或 `twitter:image`。不要用搜索结果的缩略图、别的页面的图，也不要自己拼地址。
- 必须以 https:// 开头，否则当作没有图。
- 来源页的图是全站通用图（网站 logo、日报栏目封面、每周合集封面这类和这条新闻无关的图）时，宁可省略。
- 同一个页面被几条共用时，只给最贴切的那一条配图，其余省略。
- 每个板块「重要」的第一条是头条，会以大图横幅显示，尽量把有专属配图的那条放第一。
- 已知在读者那里加载不出来的来源不填 `image`：VGC（videogameschronicle.com）。发现新的就加到这里。
- `image_alt` 用一句中文说明图片内容，可省略。

## 每日更新

1. 写好 `data/YYYY-MM-DD.json`（日期用新加坡时间当天）。
2. 把这个日期加进 `data/index.json` 的 `dates`。
3. 提交并推送到 main：

```
git add data/
git commit -m "Add digest for YYYY-MM-DD"
git push origin main
```

GitHub Pages 通常在一两分钟内更新。网址不带 `#` 时显示最新一期，`#2026-11-26` 打开指定一期。
